# Title
Research contributions: rough sets, granular computing, databases, temporal analysis

# Category
research

# Problem
Many real-world data problems involve uncertainty, approximation, and changing information, which classic exact methods handle poorly at scale. Rough sets and granular computing provide formal tools to model approximation spaces and extract rules from data.

# My role
I authored and co-authored 60+ research outputs including journal articles, book chapters, conference papers, and technical reports. My work spans rough sets, granular computing, spatio-temporal reasoning, and database-related applications of approximation.

# What I built
I contributed to foundational publications such as work on rough set algorithms for classification, dynamic reducts for extracting laws from decision tables, and approximation spaces/information granulation. I also co-authored research on rough/approximate database semantics and execution, connecting theory to engineered systems.

# Scale and impact
The publication set demonstrates sustained research rigor and breadth across theory and applied systems topics. It also provides the conceptual base for later industrial work on approximate query execution and scalable analytics platforms.

# Tech stack
Research domains include rough sets, data mining, temporal data analysis, and database engine design. Outputs include peer-reviewed venues (e.g., VLDB proceedings, journal publications) and book chapters in established series and handbooks.

# Key decisions and trade-offs
A consistent trade-off is choosing approximation to unlock scalability while preserving meaningful semantics and interpretability. I focus on bridging formal models with implementable algorithms that can be validated empirically, not just described theoretically.
