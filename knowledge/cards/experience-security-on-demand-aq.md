# Title

# Category
experience

# Problem
Threat-hunting queries over large security log datasets can be too slow for operational response if executed exactly.

# My role
Chief architect and R&D lead for the approximate query database and anomaly-detection engine.

# What I built
Created an approximate query database engine and anomaly-detection engine for real-time analysis of billions of security logs; managed the end-to-end roadmap using an AWS cloud-native architecture and Agile processes.

# Scale and impact
Reduced large-scale threat-hunting queries from hours to seconds (as stated in the CV).

# Tech stack
Approximate query database engine; cybersecurity analytics; AWS cloud-native architecture; Agile delivery; CI/CD with Jenkins; distributed R&D collaboration.

# Key decisions and trade-offs
Used approximation to trade exactness for operational speed; made architecture decisions to support scale and maintainability in a production security environment.
